# 📝 React TypeScript Conversion

This project demonstrates how to convert React JavaScript components into TypeScript components.

---

# 🚀 Features

✅ Functional component conversion  
✅ Class component conversion  
✅ Typed props  
✅ Typed state  
✅ TypeScript interfaces  
✅ Strong type safety  

---

# 🛠️ Technologies Used

- React
- TypeScript
- Vite

---

# 📦 Installation

```bash
npm install
```

---

# ▶️ Run Project

```bash
npm run dev
```
